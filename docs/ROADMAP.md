# Product Roadmap

## Vision

Build the leading platform for measuring and improving AI Visibility across AI assistants such as ChatGPT, Claude, Gemini, and Perplexity.

---

# MVP (Version 1.0)

The MVP should allow a user to:

* Register and authenticate
* Create an Organization
* Add one or more websites
* Crawl a website
* Analyze website content
* Generate an AI Visibility Score
* View recommendations
* Export a report

---

# Sprint 0 - Foundation ✅

* Next.js setup
* Authentication
* Dashboard
* Documentation
* Clean Architecture

---

# Sprint 1 - Workspace

## Goal

Users can manage organizations and websites.

Deliverables:

* Organization CRUD
* Memberships
* Website CRUD
* URL validation
* Domain normalization
* Dashboard integration

---

# Sprint 2 - Crawl Engine

## Goal

Store website content for analysis.

Deliverables:

* robots.txt parser
* sitemap.xml parser
* Page discovery
* HTML downloader
* Markdown extraction
* Page storage

---

# Sprint 3 - Analysis Engine

## Goal

Analyze every page.

Deliverables:

* Metadata analyzer
* Heading analyzer
* Structured Data analyzer
* Entity analyzer
* AI Readability analyzer
* Internal Link analyzer

---

# Sprint 4 - Scoring Engine

## Goal

Generate AI Visibility Score.

Deliverables:

* Score calculation
* Severity engine
* Recommendation engine
* Trend calculation

---

# Sprint 5 - Reporting

## Goal

Help agencies share results.

Deliverables:

* Dashboard
* PDF reports
* Scan history
* Trend charts
